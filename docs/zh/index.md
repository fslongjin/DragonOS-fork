# 欢迎来到 DragonOS 文档

DragonOS 是一个面向 **Agent Native** 时代的轻量级 64 位独立内核操作系统，使用 Rust 语言从零构建，提供 **Linux 二进制（ABI）兼容性**，专为高效、安全地运行 **AI Agent 沙箱（Sandbox）** 与 **云原生服务（Service）** 而设计。
